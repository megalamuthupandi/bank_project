# 🏦 Bank Management System

A simple Bank Management System built using **Python Flask, MySQL, HTML, and Tailwind CSS**.

This project allows users to create a bank account, login securely, view their account details, deposit money, withdraw money, and view transaction history.

---

## 🚀 Features

- User Registration
- Secure Password Hashing
- User Login & Logout
- Account Number Generation
- View Account Details
- Check Account Balance
- Deposit Money
- Withdraw Money
- Insufficient Balance Validation
- Transaction History
- MySQL Database Integration
- Flask Web Application
- Vercel Deployment Configuration

---

## 🛠️ Technologies Used
